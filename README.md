## Featured Projects

Ranked by depth, complexity, and current focus.

### 🧩 [PulseAI](https://github.com/yaswanthsetty/pulseAI) — Real-Time AI News Intelligence Platform
A production-oriented platform that ingests, clusters, and reasons over live news using a multi-agent pipeline.
- **4-agent AI pipeline** for ingestion, clustering, evidence scoring, and synthesis
- **BGE embeddings** + **UMAP + HDBSCAN** for semantic story clustering
- **Qdrant** vector storage with a fast-path / deep-path chat architecture for low-latency + high-depth querying
- Architected as a resolved **modular monolith** (post-review redesign from an over-decomposed microservice draft), with full PostgreSQL DDL and a hardened API/security layer

`Python` `Qdrant` `PostgreSQL` `Vector Search` `LLM Orchestration`

### 🌾 [Rythu Bazar](https://github.com/yaswanthsetty/rythu-bazar) — Agricultural Marketplace Platform
A full-stack marketplace connecting farmers directly to buyers, built for real transactional load.
- **60+ REST endpoints** covering auth, listings, orders, and admin operations
- **JWT refresh token rotation** and **RBAC** for secure, role-aware access control
- **Redis-based rate limiting** to protect against abuse at scale
- **95 automated tests** backing the core business logic

`JavaScript` `TypeScript` `Node.js` `Redis` `REST APIs`

An OCR pipeline built to extract and validate regulatory data from product packaging.
- **Multilingual extraction** (English + Hindi) tuned for real-world label variance

`Python` `OCR` `Computer Vision` `Rule-Based Validation`
